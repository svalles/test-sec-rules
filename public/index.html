Cloudflare Security Rules Lab

Este sitio de prueba sirve para validar reglas de seguridad en Cloudflare (WAF/Rate Limiting/Custom Rules).

Endpoints sugeridos para pruebas

  • / página principal
  • /login?user=admin consulta con query string
  • /api/search?q=test endpoint simulado para pruebas con payloads

Ejemplos de requests para validar reglas

# SQLi en query
curl "https://TU_DOMINIO/api/search?q=' OR 1=1 --"

# XSS en query
curl "https://TU_DOMINIO/login?user=%3Cscript%3Ealert(1)%3C/script%3E"

# Path traversal
curl "https://TU_DOMINIO/../../etc/passwd"

Importante: usar solo en entorno de laboratorio/controlado.
